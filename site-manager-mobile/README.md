# 사이트 링크 관리 – 휴대폰 웹앱 (안드로이드)

목록을 누르면 브라우저로 열리고, 브라우저의 **공유** 메뉴로 지금 보는 주소를 추가하거나 기존 사이트를 갱신합니다.
PC 확장 프로그램과 같은 GitHub 저장소로 동기화하면 목록과 메인 URL을 함께 씁니다.

- 주소: **https://kwanghyun-room.github.io/claude-code-guide-practice/**
- 배포: `main` 브랜치에 반영되면 `.github/workflows/pages.yml`이 자동으로 배포합니다. `common.js`는 `site-manager-extension/common.js`를 복사해서 씁니다.

## 처음 한 번: GitHub Pages 켜기

1. 저장소 **Settings → Pages**로 갑니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. 이 변경이 `main`에 합쳐진 뒤 **Actions** 탭에서 *Deploy mobile web app*이 성공하면 위 주소가 열립니다.

## 휴대폰에 설치

1. 안드로이드 크롬에서 위 주소를 엽니다.
2. 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
3. 설치해야 공유 메뉴에 **사이트 링크**가 나타납니다.

## 공유로 추가·갱신

1. 크롬에서 원하는 페이지를 연 상태로 메뉴(⋮) → **공유** → **사이트 링크**를 고릅니다.
2. 열린 창에서 고릅니다.
   - **＋ 새 사이트로 추가**: 목록 맨 아래에 넣습니다. 이름은 페이지 제목으로 채워집니다.
   - **↻ 선택한 사이트 갱신**: 고른 사이트의 경로를 이 주소로 바꿉니다. 경로가 가장 비슷한 사이트가 미리 선택됩니다.
3. 도메인이 메인 URL과 다르면 메인 URL을 바꿀지 물어봅니다.

## 편집

- 위쪽 **편집**을 누르면 각 항목에 ▲▼(순서), ✎(수정), ✕(삭제)가 나타납니다.
- 오른쪽 아래 **＋**로 직접 추가할 수 있습니다.
