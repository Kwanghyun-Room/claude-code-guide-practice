# 사이트 링크 관리 (크롬/엣지 확장 프로그램)

메인 URL을 한 곳에서 관리하고, 뷰에서 보고 있는 페이지 주소로 사이트를 바로 **추가**하거나 **갱신**하는 확장 프로그램입니다.

## 설치 (처음 한 번)

1. 이 폴더(`site-manager-extension`)를 PC의 고정된 위치에 둡니다. 설치 후 폴더를 옮기거나 지우면 확장 프로그램이 동작하지 않습니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다. 엣지는 `edge://extensions` 입니다.
3. 오른쪽 위(엣지는 왼쪽 아래)의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **사이트 링크 관리**를 고정합니다. 아이콘을 누르면 관리 화면이 열립니다.

> 회사 PC에서 개발자 모드나 확장 프로그램 설치가 정책으로 막혀 있으면 설치할 수 없습니다. 이때는 IT 담당자에게 문의하세요.

## 기존 HTML 버전에서 목록 옮기기

확장 프로그램과 기존 `site-manager/index.html`은 데이터를 따로 저장합니다.

1. 기존 HTML 화면에서 **⚙ 메인 URL · 사이트 추가 → 백업 → 내보내기**를 누릅니다.
2. 확장 프로그램 화면의 같은 위치에서 **가져오기**로 그 파일을 고릅니다.

## 휴대폰과 목록 공유 (GitHub 동기화)

PC와 휴대폰 웹앱(`site-manager-mobile`)이 GitHub **비공개** 저장소의 JSON 파일 하나를 함께 씁니다. 처음에 한 번만 준비하면 됩니다.

### 1. 목록을 저장할 비공개 저장소 만들기
- GitHub에서 **New repository**를 누르고 이름(예: `site-links`)을 정한 뒤 **Private**으로 만듭니다.
- 지금의 `claude-code-guide-practice`는 공개 저장소라서 목록 저장용으로 쓰면 안 됩니다.

### 2. 토큰 만들기 (그 저장소에만 접근하도록)
1. GitHub 오른쪽 위 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. **Repository access**: *Only select repositories* → 1번에서 만든 저장소만 고릅니다.
3. **Permissions → Repository permissions → Contents**: *Read and write*
4. 만료일을 정하고 생성한 뒤 표시되는 토큰을 복사해 둡니다. 페이지를 벗어나면 다시 볼 수 없습니다.

### 3. 각 기기에서 연결
- **PC 확장 프로그램**: **⚙ 메인 URL · 사이트 추가 → 동기화**
- **휴대폰 웹앱**: 오른쪽 위 **⚙**
- 두 곳 모두 저장소(`내아이디/site-links`), 파일 경로(비우면 `sites.json`), 토큰을 넣고 **연결**을 누릅니다.
- GitHub에 이미 목록이 있는데 이 기기 목록과 다르면, 어느 쪽을 쓸지 물어봅니다.

### 동기화 방식
- 목록이나 메인 URL을 바꾸면 1초 안에 GitHub에 저장합니다. 화면으로 돌아오면 다른 기기의 변경을 받아옵니다.
- 목록 위의 점 색으로 상태를 보여줍니다. 초록은 동기화됨, 주황은 진행 중, 빨강은 오류입니다.
- 두 기기에서 거의 동시에 바꾸면 **먼저 저장된 쪽이 우선**입니다. 나중 기기에는 최신 목록을 불러왔다는 안내가 뜨고, 방금 한 변경은 다시 해야 합니다.
- 토큰은 각 기기의 이 앱 저장소에만 보관됩니다. 기기를 잃어버렸거나 토큰이 노출됐다면 GitHub에서 그 토큰을 삭제(Revoke)하세요.
- 토큰이 만료되면 빨간 오류가 뜹니다. 새 토큰을 만들어 각 기기에서 다시 **연결**하세요.

## 뷰 주소로 추가·갱신하기

1. 목록에서 사이트를 클릭해 뷰에 엽니다.
2. 뷰 안에서 링크를 눌러 원하는 페이지로 이동합니다. 상단 주소가 실시간으로 바뀌고, 저장된 주소와 다르면 **이동됨** 표시가 뜹니다.
3. 버튼을 누릅니다.
   - **↻ 현재 사이트 갱신**: 선택한 사이트의 경로를 지금 주소로 바꿉니다.
   - **＋ 새 사이트로 추가**: 지금 주소를 선택한 사이트 바로 아래에 새 항목으로 넣습니다. 이름은 페이지 제목으로 자동 입력되고, 바로 수정할 수 있습니다.
4. 지금 주소의 도메인이 메인 URL과 다르면 메인 URL을 바꿀지 물어봅니다. **확인**을 누르면 모든 사이트에 새 도메인이 적용되고, **취소**를 누르면 저장하지 않습니다.

## 권한과 동작 범위

| 권한 | 용도 |
|---|---|
| `webNavigation` | 뷰(iframe)가 이동한 주소를 알아내기 위해 |
| `declarativeNetRequest` | 임베딩 차단 헤더(X-Frame-Options, Content-Security-Policy)를 제거하기 위해 |
| 모든 사이트 접근 | 위 두 기능과 페이지 제목 읽기를 위해 |

- 차단 헤더 제거는 **관리 화면이 열린 탭의 iframe에만** 적용됩니다. 다른 탭의 일반 브라우징에는 영향이 없고, 탭을 닫으면 규칙도 지워집니다.
- 뷰 안의 사이트는 관리 화면 전체를 자기 페이지로 바꿔치기할 수 없도록 제한(sandbox)되어 있습니다.
- 스크립트로 직접 "다른 페이지 안에 들어가 있는지"를 검사하는 일부 사이트는 여전히 제대로 보이지 않을 수 있습니다.
- 데이터는 이 브라우저의 확장 프로그램 저장소에만 있습니다. 확장 프로그램을 삭제하면 목록도 지워지니, 백업 내보내기를 해두세요.
